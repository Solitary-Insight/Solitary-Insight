## Selected Work

**[SMAS — Smart Multi-Agent Scheduling](https://github.com/Solitary-Insight/SMAS)**
University timetabling system using constraint-aware beam search to schedule courses, teachers, and rooms without conflicts. Node.js/Express, MariaDB, Next.js. Optimized the core engine for a ~1.8x speedup via deferred cloning and parallelized DB loading.

**[DairySense](https://github.com/Solitary-Insight)**
IoT cattle monitoring platform (final year project) — React Native app, admin dashboard, and a Python daemon reading live sensor data from NodeMCU/STM32 collars over LoRaWAN. Real-time WebSocket channels and FCM alerts for farm workers.

**[VoteNow](https://github.com/Solitary-Insight)**
Secure online election platform with tokenized ballot submission and real-time result visualization. Next.js, Firebase, deployed on Vercel.

**[Study Sphere](https://github.com/Solitary-Insight)**
Exam preparation platform with real-time quiz sessions and live Q&A between educators and students. Angular, Node.js, Socket.io, MySQL.
